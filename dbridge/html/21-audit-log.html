审计日志

1. 功能概述

审计日志记录系统中所有关键操作，提供完整的操作追溯能力。通过审计日志，管理员可以了解谁在什么时间执行了什么操作，操作是否成功，以及操作的详细参数。

核心能力：

  • 全量操作记录
  • 按模块和结果筛选
  • 可展开的 JSON 详情
  • 分页浏览
  • 自动清理配置

2. 进入审计日志

在左侧导航栏中，点击 审计日志 进入审计日志页面。

3. 日志列表

3.1 筛选条件

页面顶部提供两个筛选下拉框：

模块筛选：

模块 说明
全部 显示所有模块的日志
系统 系统级操作（登录、设置变更等）
数据源 数据源的增删改查操作
查询 SQL 查询执行
同步 数据同步操作
AI AI 助手相关操作
安全 安全相关操作（脱敏规则、权限变更等）
报表 报表操作
导出 数据导出操作
对比 结构对比操作

结果筛选：

结果 说明
全部 显示成功和失败的日志
成功 仅显示成功的操作
失败 仅显示失败的操作

3.2 列表字段

列名 说明
模块 操作所属模块（标签形式）
操作 具体操作类型（标签形式），如"用户登录"、“数据源创建”、“查询执行”、“DDL”、"AI 对话"等
详情 操作详情的摘要（截断显示，鼠标悬停查看完整内容）
结果 操作结果（成功为绿色标签，失败为红色标签）
操作者 执行操作的用户名
目标 操作的目标对象名称
IP 地址 操作来源 IP
时间 操作执行时间

3.3 展开详情

点击表格行前的展开箭头，可以查看操作的完整 JSON 详情。详情内容包括：

  • 请求参数
  • 操作上下文
  • 错误信息（如果操作失败）
  • 其他元数据

4. 分页

审计日志支持分页浏览，每页可选 10、20、50 条记录。页面底部显示总记录数和当前页码。

5. 自动清理

为避免审计日志无限增长，系统支持配置自动清理策略。详见 系统设置 中的审计日志清理配置。

6. 使用场景

  1. 安全审计：定期检查敏感操作（如数据源删除、用户权限变更）
  2. 问题排查：通过操作日志追溯问题发生的原因
  3. 合规检查：满足行业合规要求的操作审计需求
  4. 行为分析：了解用户的使用习惯和操作模式

7. 注意事项

  • 审计日志仅记录操作信息，不记录查询结果数据
  • 失败的日志同样会被记录，便于排查问题
  • 操作者信息基于当前登录用户，API Key 调用会记录对应的 Key 标识
  • 建议定期导出重要审计日志作为归档

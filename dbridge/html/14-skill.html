Skill 管理

Skill（技能）是可复用的 AI 提示词模板，定义了特定任务的执行方式。Skill 可以绑定工具、定义输入变量，并被 Agent 调用。

功能概述

  • 创建和管理 AI Skill
  • 提示词模板与输入变量
  • 工具绑定
  • 版本管理与回滚
  • 测试运行
  • 导入/导出
  • AI 辅助生成

Skill 列表

进入「Skill 管理」页面，以卡片网格展示所有 Skill：

信息 说明
名称 Skill 名称
图标 Skill 图标
分类 general / analysis / optimization / migration
描述 Skill 功能描述

创建 Skill

点击「新建」按钮，填写 Skill 配置：

基本信息

字段 说明
名称 Skill 名称
Slug 唯一标识（URL 友好）
描述 功能描述
图标 选择图标
分类 general / analysis / optimization / migration
启用 是否启用

提示词配置

字段 说明
提示词模板 Skill 的 Prompt 模板，支持变量插值
系统提示词 系统级指令
输入变量 模板中的变量列表
输出格式 markdown / json / yaml / text

提示词模板示例：

请分析以下 SQL 查询的性能问题：

SQL: {{sql}}
数据库类型: {{db_type}}

请给出：
1. 性能问题诊断
2. 优化建议
3. 优化后的 SQL

工具绑定

选择 Skill 执行时可调用的 MCP 工具。

脚本文件与资源

  • 脚本文件 — 关联的 SQL 脚本文件
  • 资源 — 附加的资源文件

分类说明

分类 说明 示例
general 通用技能 SQL 解释、代码生成
analysis 分析技能 数据洞察、趋势分析
optimization 优化技能 SQL 优化、索引建议
migration 迁移技能 DDL 转换、数据迁移

测试运行

创建或编辑 Skill 后，可以点击「测试运行」验证效果：

  1. 填写输入变量的值
  2. 点击「运行」
  3. 查看执行结果：
    • 工具调用追踪
    • 输出内容
    • 执行耗时

版本管理

每次保存 Skill 都会创建一个版本：

  1. 点击「版本历史」按钮
  2. 查看所有历史版本
  3. 可以回滚到任意历史版本

版本管理确保修改 Skill 时可以安全回退。

导入/导出

导出 Skill

将 Skill 导出为 ZIP 文件，包含配置和关联资源：

  1. 选择要导出的 Skill
  2. 点击「导出」
  3. 下载 ZIP 文件

导入 Skill

从 ZIP 文件导入 Skill：

  1. 点击「导入」按钮
  2. 选择 ZIP 文件
  3. 确认导入

导入/导出适合在团队间共享 Skill 配置。

AI 生成

系统支持通过 AI 自动生成 Skill：

  1. 点击「AI 生成」按钮
  2. 输入 Skill 描述
  3. AI 自动生成提示词模板、输入变量、输出格式

内置 Skill

系统预置了多个内置 Skill，如：

Skill 分类 说明
SQL 解释 general 将 SQL 翻译为自然语言
SQL 优化 optimization 分析性能并给出优化建议
数据洞察 analysis 分析查询结果，生成洞察
DDL 转换 migration 在不同数据库方言间转换 DDL

内置 Skill 不可编辑或删除，但可以基于它们创建自定义 Skill。

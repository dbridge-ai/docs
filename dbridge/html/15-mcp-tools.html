MCP 工具

MCP（Model Context Protocol）工具是 AI Agent 可以调用的功能单元。DBridge Pro 内置了丰富的 MCP 工具，同时支持创建自定义工具。

功能概述

  • 查看内置 MCP 工具
  • 创建自定义 SQL 工具
  • 编辑和删除自定义工具
  • 启用/禁用工具
  • 权限级别管理

工具列表

进入「MCP 工具」页面，展示所有可用工具：

列 说明
名称 工具显示名称
Tool ID 工具唯一标识
类型 builtin（内置）/ custom（自定义）
分类 工具所属类别
权限 read / write / admin
状态 启用/禁用开关
描述 工具功能说明

筛选

  • 搜索 — 按名称搜索
  • 分类筛选 — 按工具类别过滤
  • 类型筛选 — 内置 / 自定义

内置工具

系统预置了以下类别的 MCP 工具：

Admin 工具

工具 说明
服务器信息 获取服务器运行状态和版本信息
系统配置 查看和修改系统配置

DataSource 工具

工具 说明
数据源列表 获取所有数据源
数据源详情 获取数据源连接信息
测试连接 测试数据源连通性

Query 工具

工具 说明
执行查询 执行 SQL 查询并返回结果
执行 DML 执行 INSERT/UPDATE/DELETE

Schema 工具

工具 说明
数据库列表 获取数据库列表
表列表 获取指定库的表列表
表结构 获取表的列信息
索引信息 获取表的索引

Compare 工具

工具 说明
结构对比 对比两个数据源的结构差异
表数据对比 对比两个表的数据差异

Structure 工具

工具 说明
创建表 在目标库创建表
修改表 修改表结构
删除表 删除表

Server 工具

工具 说明
进程信息 获取数据库进程列表
用户列表 获取数据库用户
角色信息 获取角色和权限

Metric 工具

工具 说明
服务器指标 获取 CPU、内存、连接数等指标
慢查询列表 获取当前慢查询

Slow SQL 工具

工具 说明
慢 SQL 分析 分析慢查询原因
EXPLAIN 执行 EXPLAIN 获取查询计划

Semantic 工具

工具 说明
Cube 列表 获取语义层 Cube 列表
指标查询 执行语义层指标查询

自定义工具

除了内置工具，还可以创建自定义 SQL 工具：

创建自定义工具

  1. 点击「新建」按钮
  2. 填写工具信息：
字段 说明
名称 工具显示名称
Tool ID 唯一标识（英文，如 my_custom_query）
描述 工具功能说明（AI 根据此描述决定何时调用）
分类 工具类别
权限级别 read / write / admin
SQL 模板 工具执行的 SQL 语句
  1. SQL 模板支持参数占位符：
SELECT * FROM {{table_name}}
WHERE created_at >= '{{start_date}}'
LIMIT {{limit}}
  1. 保存后工具立即可用

编辑自定义工具

  1. 找到目标工具
  2. 点击「编辑」按钮
  3. 修改配置
  4. 保存

内置工具不可编辑。

删除自定义工具

  1. 找到目标工具
  2. 点击「删除」按钮
  3. 确认后删除

内置工具不可删除。

启用/禁用

通过开关控制工具是否可用：

  • 启用 — Agent 可以调用该工具
  • 禁用 — Agent 无法调用该工具

禁用工具不会删除配置，随时可以重新启用。

权限级别

级别 说明 示例
read 只读操作 查询、查看结构
write 写操作 创建表、修改数据
admin 管理操作 删除表、修改配置

Agent 调用工具时，系统会检查 Agent 的数据源权限是否满足工具的权限要求。

工具详情

点击工具名称打开详情 Drawer，查看：

  • 完整的工具配置
  • SQL 模板
  • 参数定义
  • 使用说明
  • 调用示例

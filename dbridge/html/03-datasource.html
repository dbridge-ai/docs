数据源管理

数据源是 DBridge Pro 连接外部数据库的配置。所有数据库操作都基于已配置的数据源。

功能概述

  • 创建、编辑、删除数据库连接
  • 支持 7 种数据库类型
  • SSH 隧道连接
  • SSL/TLS 加密连接
  • 连接测试
  • 数据源导入/导出
  • 标签和环境标记

支持的数据源类型

数据库 连接方式 特殊配置
MySQL TCP 标准连接参数
MariaDB TCP 同 MySQL
OceanBase TCP 同 MySQL
PostgreSQL TCP SSL Mode
SQL Server TCP 标准连接参数
Oracle TCP Service Name / SID、连接模式、角色
SQLite 文件 文件上传或存储浏览

创建数据源

步骤

  1. 进入「数据源管理」页面
  2. 点击 「新建」 按钮
  3. 填写连接信息（见下方说明）
  4. 点击 「测试连接」 确认连通性
  5. 点击 「确定」 保存

连接信息

创建数据源的弹窗包含 4 个标签页：

连接信息标签页

字段 说明 必填
名称 数据源的显示名称 是
类型 数据库类型（MySQL / PostgreSQL / Oracle / SQL Server / SQLite） 是
主机 数据库服务器地址（SQLite 除外） 是
端口 数据库端口号（SQLite 除外） 是
数据库 数据库名称（SQLite 为文件路径） 是
用户名 数据库用户名（SQLite 除外） 是
密码 数据库密码（AES-256-GCM 加密存储） 是

TLS/SSL 标签页

用于配置加密连接：

字段 说明
客户端证书 TLS 客户端证书文件内容
客户端密钥 TLS 客户端私钥文件内容
根证书 CA 根证书文件内容

SSH 隧道标签页

当数据库服务器不能直接访问时，可以通过 SSH 隧道连接：

字段 说明
SSH 主机 跳板机地址
SSH 端口 SSH 端口（默认 22）
SSH 用户名 登录用户名
认证方式 密码 / 密钥 / 密钥+密码 / Agent / 无
超时时间 连接超时（秒）

高级标签页

额外的驱动参数，以 JSON 格式配置。

Oracle 特殊配置

Oracle 数据源有额外的连接选项：

字段 选项 说明
连接模式 Service Name / SID Oracle 连接标识类型
角色 Default / SYSDBA / SYSOPER 连接权限级别

SQLite 特殊配置

SQLite 数据源有两种配置方式：

  • 文件上传 — 直接上传 .db / .sqlite 文件
  • 存储浏览 — 从已配置的文件存储中选择

数据源列表

列表展示所有已配置的数据源，包含以下信息：

列 说明
名称 数据源名称
类型 数据库类型（彩色标签）
主机:端口 连接地址
数据库 数据库名
用户名 连接用户名
环境 dev / test / prod 标记
标签 功能标签（database_management / data_query）
操作 查询、编辑、删除

筛选与搜索

  • 搜索框 — 按名称搜索
  • 标签筛选 — 按功能标签过滤
  • 环境筛选 — 按环境标记过滤

连接测试

在创建/编辑弹窗中，点击 「测试连接」 按钮：

  • 成功 — 显示绿色提示 “连接成功”
  • 失败 — 显示红色错误信息和具体原因

测试时会验证：

  • 网络连通性
  • 用户名/密码正确性
  • 数据库是否存在
  • SSH 隧道可用性（如配置了 SSH）

标签与环境

功能标签

为数据源添加功能标签，控制其在系统中的可见范围：

标签 说明
database_management 在数据库管理页面可见
data_query 在 SQL 编辑器中可见

环境标记

标记数据源所属环境，便于区分：

环境 颜色 说明
dev 绿色 开发环境
test 黄色 测试环境
prod 红色 生产环境

导入/导出

导出数据源

将数据源配置导出为 JSON 文件（密码加密保护）：

  1. 点击工具栏 「导出」 按钮
  2. 选择要导出的数据源
  3. 设置导出密码
  4. 下载 JSON 文件

导入数据源

从 JSON 文件导入数据源配置：

  1. 点击工具栏 「导入」 按钮
  2. 选择 JSON 文件
  3. 输入导入密码
  4. 确认导入

导入/导出功能适合在团队间共享数据源配置，或在不同环境间迁移。

密码安全

数据源密码采用 AES-256-GCM 对称加密：

  • 存储时加密 — 密码在写入数据库前加密
  • API 不返回 — 接口响应中永远不包含密码字段
  • 密钥管理 — 加密密钥通过环境变量 DBRIDGE_CRYPTO_KEY 配置

快速操作

在数据源列表中，每行提供快捷操作：

操作 说明
查询 直接在 SQL 编辑器中打开该数据源
编辑 修改数据源配置
删除 删除数据源（需确认）

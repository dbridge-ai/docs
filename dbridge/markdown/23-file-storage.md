# 文件与存储管理

## 1. 功能概述

DBridge 提供完整的文件管理和存储管理能力。文件管理页面用于浏览、上传、下载和管理文件；存储管理页面用于配置存储后端实例和模块绑定。系统支持本地文件系统和 S3 兼容存储两种后端。

**核心能力**：
- 目录树导航与文件浏览
- 文件上传、下载、批量操作
- 多存储实例管理（本地 / S3）
- 跨存储实例的文件复制、移动和同步
- 模块级存储绑定

---

## 2. 文件管理

### 2.1 进入文件管理

在左侧导航栏中，点击 **文件管理** 进入文件管理页面。

### 2.2 页面布局

文件管理页面分为左右两个区域：

**左侧面板**：
- **存储实例选择器**：下拉框切换不同的存储实例，显示配额使用情况（已用/总量）
- **目录树**：树形结构展示文件夹层级，点击文件夹展开或导航

**右侧面板**：
- **面包屑导航**：显示当前路径，点击可快速跳转到上级目录
- **文件列表**：表格形式展示当前目录下的文件和文件夹

### 2.3 文件操作

| 操作 | 说明 |
|------|------|
| 上传文件 | 点击 **上传** 按钮，选择本地文件上传到当前目录 |
| 新建文件夹 | 点击 **新建文件夹** 按钮，输入文件夹名称 |
| 下载 | 在文件操作栏点击 **下载** 按钮 |
| 重命名 | 在文件操作栏点击 **重命名** 按钮，输入新名称 |
| 删除 | 在文件操作栏点击 **删除** 按钮，确认后删除 |
| 复制到 | 将文件复制到其他存储实例或目录 |
| 移动到 | 将文件移动到其他存储实例或目录 |

### 2.4 批量操作

勾选多个文件后，顶部工具栏显示批量操作按钮：

| 操作 | 说明 |
|------|------|
| 批量下载 | 将选中的文件打包为 ZIP 下载 |
| 批量复制 | 将选中的文件批量复制到其他位置 |
| 批量移动 | 将选中的文件批量移动到其他位置 |
| 同步到 | 将选中的文件同步到其他存储实例 |
| 批量删除 | 批量删除选中的文件 |

> **注意**：目录不支持勾选，批量操作仅针对文件。

### 2.5 搜索

在搜索框中输入关键词，可以快速过滤当前目录下的文件。

### 2.6 跨存储操作

**复制/移动**：

1. 选中文件后，点击 **复制** 或 **移动** 按钮
2. 在弹出的对话框中，选择目标存储实例
3. 选择目标路径
4. 勾选是否覆盖已有文件
5. 确认执行

**同步**：

1. 选中文件后，点击 **同步到** 按钮
2. 在同步对话框中配置目标存储和路径
3. 确认执行同步

## 3. 存储管理

### 3.1 进入存储管理

在左侧导航栏中，点击 **存储管理** 进入存储管理页面。

### 3.2 存储实例

切换到 **实例** 标签页，管理存储后端实例。

**实例列表字段**：

| 列名 | 说明 |
|------|------|
| 名称 | 存储实例名称（默认实例带星标） |
| 编码 | 唯一标识编码 |
| 后端类型 | 本地（Local）或 S3 |
| 连接状态 | 未测试 / 已连接 / 连接失败 |
| 启用状态 | 开关控制是否启用 |
| 操作 | 测试连接、编辑、删除 |

**创建存储实例**：

点击 **添加实例** 按钮，填写以下信息：

*本地存储*：
- 名称
- 编码（唯一标识，创建后不可修改）
- 后端类型：选择"本地"
- 根目录：本地文件系统路径

*S3 存储*：
- 名称
- 编码
- 后端类型：选择"S3"
- Bucket：S3 桶名
- Endpoint：S3 服务端点
- Region：区域
- Access Key：访问密钥
- Secret Key：密钥

> **提示**：系统会自动识别 MinIO（根据 Endpoint 特征），并调整相应的配置。

**测试连接**：点击 **测试连接** 按钮，验证存储配置是否正确。

**设为默认**：每个存储类型只能有一个默认实例。默认实例用于系统模块的默认存储。

### 3.3 模块绑定

切换到 **绑定** 标签页，管理系统模块与存储实例的绑定关系。

绑定配置包括：
- **模块名称**：使用存储的系统模块
- **存储实例**：绑定的存储实例（仅显示已启用的实例）
- **基础路径**：该模块在存储中的根路径

> **路径限制**：基础路径不允许包含 `..`、不允许使用绝对路径、不允许包含特殊字符。

## 4. 配额管理

每个存储实例可以配置存储配额。在文件管理页面的存储实例选择器旁，显示当前配额使用情况（如 `2.5 GB / 10 GB`）。

系统配置中也可以设置全局的文件上传限制：

| 配置项 | 说明 |
|--------|------|
| 单文件上限 | 单个文件的最大大小 |
| 目录深度 | 允许的最大目录嵌套层级 |
| 总配额 | 存储总容量限制 |
| 允许的文件类型 | 允许上传的文件扩展名列表 |

---

## 5. 使用场景

1. **SQL 文件管理**：上传和管理 SQL 脚本文件
2. **数据导入**：上传 CSV、JSON 等数据文件用于导入
3. **备份管理**：存储数据库备份文件
4. **报表资源**：管理报表使用的数据文件和模板
5. **多环境存储**：为开发、测试、生产环境配置不同的存储实例

---

## 6. 最佳实践

1. **生产环境使用 S3**：S3 存储具有更好的可靠性和扩展性
2. **定期清理**：删除不再需要的文件，释放存储空间
3. **合理组织目录**：使用目录结构组织文件，便于管理
4. **设置配额**：为存储实例设置配额，防止磁盘空间耗尽
5. **测试连接**：创建存储实例后，务必测试连接是否正常

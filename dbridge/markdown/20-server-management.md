# 服务器管理

## 1. 功能概述

服务器管理提供对数据库服务器运行状态的全面监控和管理能力。针对不同的数据库类型，系统展示对应的管理标签页，包括概览信息、实时监控、进程管理、用户管理、角色管理、表空间管理等。

**核心能力**：
- 数据库概览信息展示
- 实时性能指标监控
- 进程/会话管理
- 用户与角色管理
- 表空间管理
- 数据库类型自适应标签页

---

## 2. 进入服务器管理

1. 进入 **数据源管理** 页面
2. 找到目标数据源，点击操作栏的 **服务器管理** 按钮（显示器图标）
3. 系统根据数据库类型加载对应的管理标签页

---

## 3. 标签页说明

服务器管理的标签页根据数据库类型动态显示。以下是各标签页的详细说明。

### 3.1 概览（Overview）

概览标签页展示数据库服务器的基本信息和关键运行指标。不同数据库类型使用不同的概览组件：

| 数据库类型 | 概览组件 |
|-----------|---------|
| MySQL / MariaDB / OceanBase | MySQL 概览 |
| PostgreSQL | PostgreSQL 概览 |
| Oracle | Oracle 概览 |
| SQL Server | SQL Server 概览 |
| SQLite | SQLite 概览 |

概览信息通常包括：
- 数据库版本
- 运行时间（Uptime）
- 连接数统计
- 数据库大小
- 关键配置参数
- 字符集与排序规则

### 3.2 实时监控（Monitor）

实时监控标签页展示数据库的性能指标仪表盘，包括：

- **连接指标**：当前连接数、活跃连接数、等待连接数
- **查询指标**：每秒查询数（QPS）、慢查询数
- **缓存指标**：缓冲池命中率、缓存使用情况
- **锁指标**：锁等待数、死锁数
- **复制指标**：主从延迟、复制状态

指标数据自动刷新，以图表形式直观展示。

### 3.3 数据库列表（Databases）

展示服务器上的所有数据库列表，包括：
- 数据库名称
- 大小
- 表数量
- 字符集
- 创建时间

### 3.4 进程管理（Processes）

展示当前数据库的活动进程/会话列表：

| 列名 | 说明 |
|------|------|
| 进程 ID | 会话/进程标识 |
| 用户 | 连接用户 |
| 数据库 | 目标数据库 |
| 命令 | 当前执行的命令类型 |
| 执行时间 | 已执行时长 |
| 状态 | 进程状态 |
| 信息 | SQL 文本或状态信息 |

支持的操作：
- **刷新**：重新加载进程列表
- **终止**：结束指定进程（需要相应权限）

### 3.5 用户管理（Users）

展示数据库用户列表，支持用户的查看和管理操作。

> **权限要求**：用户管理需要数据库管理员权限。

### 3.6 角色管理（Roles）

展示数据库角色列表，仅在数据库支持角色功能时显示（如 PostgreSQL）。

### 3.7 表空间管理（Tablespaces）

展示数据库的表空间使用情况：
- 表空间名称
- 总大小
- 已使用大小
- 使用率
- 状态

### 3.8 慢 SQL（Slow SQL）

集成慢 SQL 监控功能，详见 [慢 SQL 监控](./18-slow-sql.md)。

### 3.9 巡检（Inspection）

集成数据库巡检功能，详见 [数据库巡检](./19-inspection.md)。

## 4. 数据库特有标签页

某些标签页仅在特定数据库类型下显示。

### 4.1 SQL Server 专有

| 标签页 | 说明 |
|--------|------|
| 登录名（Logins） | 管理 SQL Server 登录账户 |
| 数据库安全（Security） | 查看数据库级别的安全配置 |

### 4.2 PostgreSQL 专有

| 标签页 | 说明 |
|--------|------|
| 扩展（Extensions） | 管理 PostgreSQL 扩展插件，支持安装和卸载 |

### 4.3 SQLite 专有

| 标签页 | 说明 |
|--------|------|
| 存储（Storage） | 查看 SQLite 文件的存储信息 |
| PRAGMA 配置 | 查看和修改 SQLite PRAGMA 设置 |

---

## 5. 权限控制

服务器管理的各项功能受以下因素控制：

1. **数据库类型**：不同数据库支持不同的管理功能
2. **能力集（Capabilities）**：系统根据连接测试返回的能力集决定显示哪些标签页
3. **功能标志（Feature Flags）**：某些功能（如巡检）可通过系统配置开关
4. **数据库用户权限**：执行管理操作需要相应的数据库权限

---

## 6. 使用建议

1. **日常监控**：通过概览和实时监控标签页，了解数据库运行状态
2. **问题排查**：结合进程管理、慢 SQL、巡检功能排查性能问题
3. **安全管理**：定期审查用户和角色权限
4. **容量规划**：关注表空间使用率和数据库大小趋势
5. **及时终止异常进程**：发现长时间运行或异常的进程，及时终止

# IM 机器人

## 1. 功能概述

IM 机器人功能将 DBridge 的 AI 助手接入企业即时通讯平台，让用户在钉钉、飞书、企业微信中直接与 AI 对话，完成数据查询、分析等任务。

**核心能力**：
- 支持钉钉、飞书、企业微信三大平台
- 绑定 AI Agent 实现智能对话
- 连接状态实时监控
- 一键启停机器人

---

## 2. 进入机器人管理

在左侧导航栏中，点击 **IM 机器人** 进入机器人管理页面。

---

## 3. 创建机器人

### 3.1 基本信息

点击 **创建机器人** 按钮，在弹出的对话框中填写：

| 字段 | 说明 |
|------|------|
| 名称 | 机器人名称，用于在列表中标识 |
| IM 类型 | 选择接入平台：企业微信 / 飞书 / 钉钉 |
| 绑定 Agent | 选择关联的 AI Agent（可选） |

### 3.2 平台配置

根据选择的 IM 类型，需要填写不同的平台配置信息。

**企业微信（WeCom）**：

| 字段 | 说明 |
|------|------|
| Bot ID | 企业微信机器人的 ID |
| Secret | 企业微信机器人的密钥 |

**钉钉（DingTalk）**：

| 字段 | 说明 |
|------|------|
| App Key | 钉钉应用的 App Key |
| App Secret | 钉钉应用的 App Secret |

**飞书（Feishu/Lark）**：

| 字段 | 说明 |
|------|------|
| App ID | 飞书应用的 App ID |
| App Secret | 飞书应用的 App Secret |
| Encrypt Key | 加密密钥（可选，用于消息加密） |
| Verification Token | 验证令牌（可选，用于事件验证） |

---

## 4. 管理机器人

### 4.1 机器人列表

| 列名 | 说明 |
|------|------|
| 名称 | 机器人名称 |
| IM 类型 | 接入平台类型 |
| 启用状态 | 开关控制机器人是否启用 |
| 连接状态 | 当前连接状态（已连接 / 未连接 / 连接中 / 连接失败） |
| 最后连接时间 | 最近一次成功连接的时间 |
| 操作 | 编辑、删除 |

### 4.2 启用/禁用

通过启用状态的开关控制机器人的连接：

- **开启**：系统自动连接到对应的 IM 平台
- **关闭**：系统断开与 IM 平台的连接

### 4.3 编辑机器人

点击 **编辑** 按钮，可以修改机器人的名称、IM 类型、绑定 Agent 和平台配置。

### 4.4 删除机器人

点击 **删除** 按钮，确认后删除机器人。删除前系统会自动断开连接。

---

## 5. 平台接入指南

### 5.1 企业微信接入

1. 登录企业微信管理后台
2. 进入"应用管理" > "自建"
3. 创建新应用，获取 Bot ID 和 Secret
4. 配置回调地址指向 DBridge 的 Webhook 端点
5. 在 DBridge 中创建机器人，填入 Bot ID 和 Secret

### 5.2 钉钉接入

1. 登录钉钉开放平台
2. 创建企业内部应用
3. 在"凭证与基础信息"中获取 App Key 和 App Secret
4. 配置机器人消息接收地址
5. 在 DBridge 中创建机器人，填入 App Key 和 App Secret

### 5.3 飞书接入

1. 登录飞书开放平台
2. 创建企业自建应用
3. 在"凭证与基础信息"中获取 App ID 和 App Secret
4. 配置事件订阅地址
5. （可选）配置消息加密和事件验证
6. 在 DBridge 中创建机器人，填入相关配置

---

## 6. Agent 绑定

机器人可以绑定一个 AI Agent，实现智能对话能力。

### 6.1 绑定方式

创建或编辑机器人时，在"绑定 Agent"下拉框中选择一个 Agent。

### 6.2 对话流程

1. 用户在 IM 平台中 @机器人 或发送消息
2. IM 平台将消息转发到 DBridge
3. DBridge 使用绑定的 Agent 处理消息
4. Agent 调用工具（如查询数据库、分析数据等）
5. 将结果返回给 IM 平台
6. 用户在 IM 中看到回复

### 6.3 未绑定 Agent

如果机器人未绑定 Agent，则仅能接收消息，无法进行智能对话。

---

## 7. 连接状态

| 状态 | 说明 |
|------|------|
| 已连接 | 机器人正常运行，可以接收和回复消息 |
| 未连接 | 机器人已禁用或未启动连接 |
| 连接中 | 正在尝试连接到 IM 平台 |
| 连接失败 | 连接失败，请检查配置信息是否正确 |

---

## 8. 注意事项

1. **网络要求**：DBridge 服务器需要能够访问 IM 平台的 API 端点
2. **回调地址**：IM 平台需要能够回调到 DBridge 的 Webhook 端点
3. **权限配置**：在 IM 平台中需要为应用配置相应的权限
4. **消息限制**：各 IM 平台对消息长度和发送频率有限制
5. **安全性**：建议配置 Encrypt Key 和 Verification Token（飞书）以增强安全性

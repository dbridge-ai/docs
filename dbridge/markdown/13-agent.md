# Agent 管理

Agent（智能体）是 DBridge Pro AI 能力的核心单元。每个 Agent 定义了 AI 的行为方式、可用工具、权限范围等，驱动 AI 助手、报表生成、数据库巡检等功能。

## 功能概述

- 创建和管理 AI Agent
- 配置系统提示词和输出格式
- 绑定 MCP 工具和 Skill
- 子 Agent 编排
- 数据源权限控制
- AI 辅助生成 Agent
- 执行追踪

## Agent 列表

进入「Agent 管理」页面，展示所有 Agent：

| 列 | 说明 |
|:---|:-----|
| 名称 | Agent 名称 |
| 描述 | Agent 功能描述 |
| Runner 类型 | sdk / lite |
| 模型 | 使用的 AI 模型 |
| 范围 | user（个人）/ global（全局） |
| 操作 | 编辑、删除、查看追踪 |

## 创建 Agent

点击「新建」按钮，填写 Agent 配置：

### 基本信息

| 字段 | 说明 |
|:-----|:-----|
| 名称 | Agent 名称 |
| 描述 | Agent 功能描述 |
| Runner 类型 | sdk（完整功能）/ lite（轻量单轮） |
| 流式输出 | 是否启用流式输出 |

### Runner 类型

| 类型 | 说明 | 适用场景 |
|:-----|:-----|:---------|
| sdk | 完整 Agent，支持多轮对话、记忆、工具调用 | AI 助手、复杂任务 |
| lite | 轻量 Agent，单轮执行，无记忆 | 辅助工具、一次性生成 |

### 提示词配置

| 字段 | 说明 |
|:-----|:-----|
| 系统提示词 | Agent 的行为指令（定义角色、能力、约束） |
| 结果格式 | 期望的输出结构 |
| 输出格式 | markdown / json / yaml / text |

**系统提示词示例**：

```
你是一个数据库助手，专门帮助用户编写和优化 SQL 查询。
规则：
1. 只生成 SELECT 语句
2. 始终添加 LIMIT 限制
3. 使用用户指定的数据库方言
4. 解释你的 SQL 逻辑
```

### 模型配置

| 字段 | 说明 |
|:-----|:-----|
| 模型 | 选择 AI 模型（来自已配置的 Provider） |
| 温度 | 控制输出随机性（0-1，SQL 生成建议 0.1） |
| Max Tokens | 最大输出 Token 数 |

### 工具绑定

| 类型 | 说明 |
|:-----|:-----|
| MCP 工具 | 选择 Agent 可调用的 MCP 工具 |
| Skills | 关联的 AI Skill |
| 子 Agent | 可委派的子 Agent |

### 数据源权限

精细控制 Agent 可以访问的数据源：

| 字段 | 说明 |
|:-----|:-----|
| 数据源 | 选择允许访问的数据源 |
| 数据库 | 限制到特定数据库 |
| Schema | 限制到特定 Schema |
| 权限 | read / write / admin |

> 未配置数据源权限的 Agent 可以访问所有数据源。建议按最小权限原则配置。

## AI 生成 Agent

系统支持通过 AI 自动生成 Agent 配置：

1. 点击「AI 生成」按钮
2. 输入 Agent 描述，如："一个专门用于数据库巡检的 Agent"
3. AI 自动生成：
   - 系统提示词
   - 推荐的工具绑定
   - 输出格式

## 内置 Agent

系统预置了多个内置 Agent：

| Agent | 说明 |
|:------|:-----|
| 数据库助手 | 通用 SQL 查询助手，用于 AI 助手页面 |
| 报表生成 | 根据描述自动生成 SQL 报表 |
| Cube 生成 | 根据描述生成语义层 Cube 模型 |
| 敏感词规则生成 | 分析表结构生成数据脱敏规则 |
| Agent 生成 | 根据描述生成新的 Agent 配置 |
| Skill 生成 | 根据描述生成新的 Skill 配置 |

## 执行追踪

点击 Agent 列表中的「追踪」按钮，查看执行历史：

| 信息 | 说明 |
|:-----|:-----|
| 执行时间 | 何时执行 |
| 输入 | 用户输入内容 |
| 输出 | Agent 输出内容 |
| 工具调用 | 调用了哪些 MCP 工具 |
| 安全操作 | 触发的安全规则 |
| 耗时 | 执行时长 |
| Token 消耗 | 输入/输出 Token 数 |

## 使用场景

### 数据库查询助手

```
名称：数据库助手
提示词：你是一个数据库查询助手，帮助用户编写 SQL
工具：query_execute, schema_info
权限：read（只读）
```

### 数据库巡检

```
名称：巡检助手
提示词：分析数据库性能指标，生成巡检报告
工具：server_metrics, slow_sql_list, process_info
输出格式：markdown
```

### 报表生成

```
名称：报表生成器
提示词：根据用户描述生成 SQL 报表
工具：query_execute, schema_info
输出格式：json
```

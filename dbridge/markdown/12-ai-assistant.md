# AI 助手

AI 助手是 DBridge Pro 的智能对话界面，支持自然语言查询数据库、SQL 解释、性能优化等功能。

## 功能概述

- 多会话对话管理
- 流式输出（SSE）
- 绑定数据源和 Schema
- SQL 块内联执行
- AI Skill 快捷标签
- 多种执行模式
- 斜杠命令

## 会话管理

### 创建会话

1. 点击 **「+ 新会话」** 按钮
2. 系统创建一个新的对话会话
3. 会话标题默认为「新会话」

### 切换会话

点击左侧会话列表中的会话项，切换到该会话：
- 加载历史消息
- 恢复绑定的数据源和 Schema

### 重命名会话

- 双击会话标题
- 或点击编辑图标
- 输入新名称后保存

### 删除会话

点击删除图标，确认后删除会话及其所有消息。

### 搜索会话

在搜索框中输入关键词，按标题过滤会话列表。

### 折叠面板

点击折叠按钮，隐藏左侧会话面板，对话区域占满全宽。折叠状态会记住。

## 对话功能

### 发送消息

1. 在底部输入框中输入问题
2. 按 Enter 或点击发送按钮
3. AI 流式返回回答

### SQL 块操作

AI 回答中的 SQL 代码块提供以下操作按钮：

| 按钮 | 说明 |
|:-----|:-----|
| ▶ 执行 | 在绑定的数据源上执行该 SQL |
| 📋 复制 | 复制 SQL 到剪贴板 |
| ⚡ 优化 | 让 AI 优化这条 SQL |
| 💡 解释 | 让 AI 解释这条 SQL |

执行结果以内联表格展示在消息中。

### AI Skill 标签

输入框上方显示可用的 AI Skill 标签，点击后自动填充 Prompt 模板：

- 解释 SQL
- 优化 SQL
- 生成 SQL
- 数据洞察
- ...

### 执行模式

在输入区域可以选择 SQL 执行模式：

| 模式 | 说明 |
|:-----|:-----|
| auto | 自动执行 AI 生成的 SQL |
| approval | 需要人工审批后才执行 |
| yolo | 无限制执行（谨慎使用） |

### 审批卡片

在 approval 模式下，AI 生成的 SQL 会显示审批卡片：

- 查看 SQL 内容
- 查看风险等级
- 点击「批准」执行
- 点击「拒绝」取消

## 斜杠命令

在输入框中可以使用斜杠命令：

| 命令 | 说明 |
|:-----|:-----|
| /clear | 清空当前会话上下文 |
| /compact | 压缩当前会话上下文 |
| /memory | 查看当前记忆状态 |

## 绑定数据源

在对话前，选择要操作的数据库上下文：

| 选项 | 说明 |
|:-----|:-----|
| Agent | 选择 AI Agent（决定 AI 的行为和能力） |
| 数据源 | 选择要查询的数据库连接 |
| Schema | 选择数据库/Schema |

> 绑定数据源后，AI 会自动获取 Schema 信息，生成更准确的 SQL。

## 对话模式

AI 助手支持三种对话模式：

| 模式 | 说明 |
|:-----|:-----|
| chat | 自由对话，Text-to-SQL |
| explain | SQL 解释模式 |
| optimize | SQL 优化模式 |

## 运行追踪

点击消息旁的「查看追踪」按钮，可以查看 AI 执行的详细过程：

- 工具调用记录
- 安全操作日志
- Token 消耗
- 执行耗时

## 自动标题

当会话标题为「新会话」时，系统会自动将第一条用户消息的前 20 个字符作为会话标题。

## 使用技巧

### 高效提问

- 明确指定表名和字段名
- 描述业务需求而非技术实现
- 逐步细化：先查大致结果，再追问细节

### 多轮对话

AI 助手支持多轮对话，可以基于上下文追问：

```
👤 查询最近 7 天的订单总额
🤖 SELECT SUM(amount) FROM orders WHERE ...

👤 按天分组看看
🤖 SELECT DATE(created_at), SUM(amount) ... GROUP BY ...

👤 加上订单数
🤖 SELECT DATE(created_at), COUNT(*), SUM(amount) ...
```

### 结合 SQL 编辑器

1. 在 AI 助手中生成 SQL
2. 点击「执行」查看结果
3. 满意后复制到 SQL 编辑器中进一步修改

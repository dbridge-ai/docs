# 导出与导入

导出与导入功能提供数据库级别的数据迁移能力，支持跨库迁移、备份恢复等场景。

## 功能概述

- 导出数据库结构和数据为 SQL 文件
- 从数据库、上传文件、文件存储三种方式导入
- 支持选择导出范围（指定表 / 整个 Schema）
- 支持选择导出内容（结构+数据 / 仅结构 / 仅数据）
- 导入冲突策略（失败 / 跳过 / 替换）
- 任务化管理，支持查看执行日志

## 导出任务

### 创建导出任务

1. 进入「导出任务」页面
2. 点击 **「新建导出」** 按钮
3. 填写导出配置：

| 字段 | 说明 |
|:-----|:-----|
| 数据源 | 选择要导出的数据库连接 |
| 数据库 | 选择要导出的数据库 |
| Schema | 选择 Schema（PostgreSQL / SQL Server） |
| 范围 | 选定表 / 整个 Schema |
| 内容 | 结构+数据 / 仅结构 / 仅数据 |
| 格式 | SQL |
| 批次大小 | 每批导出的行数（默认 5000） |

4. 如果选择「选定表」，勾选要导出的表
5. 点击「确定」创建任务

### 导出内容选项

| 选项 | 说明 |
|:-----|:-----|
| 结构+数据 | 导出 CREATE TABLE + INSERT 语句 |
| 仅结构 | 只导出 CREATE TABLE 语句 |
| 仅数据 | 只导出 INSERT 语句 |

### 导出产物

导出完成后，生成 SQL 文件，包含：
- CREATE TABLE 语句（含索引、约束）
- INSERT INTO 语句（数据行）
- 注释和分隔符

## 导入任务

### 创建导入任务

导入支持三种数据来源：

#### 方式一：数据库到数据库

1. 选择源数据源和 Schema
2. 选择要导入的表
3. 选择目标数据源和 Schema
4. 配置导入选项

#### 方式二：上传文件

1. 上传 SQL 文件（支持 .sql、.zip）
2. 选择目标数据源和 Schema
3. 配置导入选项

#### 方式三：从文件存储选择

1. 从已配置的文件存储中浏览
2. 选择要导入的文件
3. 选择目标数据源和 Schema
4. 配置导入选项

### 导入选项

| 选项 | 说明 |
|:-----|:-----|
| 目标数据源 | 导入到哪个数据库连接 |
| 目标数据库 | 导入到哪个数据库 |
| 目标 Schema | 导入到哪个 Schema |
| 内容 | 结构+数据 / 仅结构 / 仅数据 |
| 冲突策略 | 失败 / 跳过 / 替换 |
| 跳过安全检查 | 跳过目标表存在性检查 |

### 冲突策略

| 策略 | 说明 |
|:-----|:-----|
| 失败 | 目标表已存在时报错停止 |
| 跳过 | 目标表已存在时跳过该表 |
| 替换 | 删除目标表后重新创建 |

## 任务管理

### 任务列表

| 列 | 说明 |
|:---|:-----|
| 类型 | 导出 / 导入 |
| 数据源 | 源/目标数据源 |
| 状态 | pending / running / completed / failed |
| 进度 | 执行进度 |
| 操作 | 启动 / 取消 / 删除 / 查看详情 |

### 执行详情

点击「查看详情」展开子表，展示执行步骤：

| 信息 | 说明 |
|:-----|:-----|
| 步骤名 | 当前执行的步骤 |
| 状态 | 成功 / 失败 / 进行中 |
| 日志 | 执行日志（可查看详细内容） |
| Manifest | 导出/导入的文件清单 |

### 从导出创建导入

导出完成后，可以直接基于导出结果创建导入任务：

1. 在导出任务列表中点击「创建导入」按钮
2. 系统自动填充源信息（导出产物作为导入源）
3. 选择目标数据源
4. 配置导入选项
5. 执行导入

## 使用场景

### 数据库迁移

```
1. 在源库创建导出任务（结构+数据）
2. 等待导出完成
3. 基于导出结果创建导入任务
4. 选择目标库，配置冲突策略为「替换」
5. 执行导入
```

### 数据备份

```
1. 创建导出任务
2. 选择「仅结构」或「结构+数据」
3. 下载导出的 SQL 文件
4. 保存到安全位置
```

### 环境同步

```
1. 从生产环境导出数据（仅结构）
2. 导入到测试环境
3. 冲突策略选择「替换」
4. 测试环境获得与生产一致的结构
```

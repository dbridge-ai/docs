# 系统设置

## 1. 功能概述

系统设置页面提供全局配置管理能力，包括主题切换和审计日志自动清理配置。

**核心能力**：
- 主题切换（亮色/暗色/跟随系统）
- 审计日志自动清理
- 清理策略配置

---

## 2. 进入系统设置

在左侧导航栏中，点击 **系统设置** 进入设置页面。

---

## 3. 主题切换

页面顶部提供主题切换组件，支持以下主题：

| 主题 | 说明 |
|------|------|
| 亮色 | 浅色背景，适合日间使用 |
| 暗色 | 深色背景，适合夜间使用 |
| 跟随系统 | 自动匹配操作系统的主题设置 |

切换主题后即时生效，无需刷新页面。

---

## 4. 审计日志清理

为避免审计日志无限增长占用存储空间，系统支持配置自动清理策略。

### 4.1 启用自动清理

通过 **启用自动清理** 开关控制是否开启自动清理功能。关闭开关后，下方的配置项会被禁用。

### 4.2 配置项

| 配置项 | 说明 | 默认值 | 范围 |
|--------|------|--------|------|
| 保留天数 | 审计日志保留的最大天数 | 90 天 | 1 - 365 天 |
| 清理时间 | 清理任务的执行时间（Cron 表达式） | `0 3 * * *` | 标准 Cron 格式 |
| 批量删除数量 | 每次清理删除的记录数 | 1000 条 | 100 - 5000 条 |

### 4.3 Cron 表达式说明

清理时间使用 Cron 表达式格式：

```
┌───────────── 分钟 (0 - 59)
│ ┌───────────── 小时 (0 - 23)
│ │ ┌───────────── 日 (1 - 31)
│ │ │ ┌───────────── 月 (1 - 12)
│ │ │ │ ┌───────────── 星期 (0 - 6)
│ │ │ │ │
* * * * *
```

**常用示例**：

| 表达式 | 说明 |
|--------|------|
| `0 3 * * *` | 每天凌晨 3:00 |
| `0 2 * * 0` | 每周日凌晨 2:00 |
| `0 4 1 * *` | 每月 1 日凌晨 4:00 |
| `0 */6 * * *` | 每 6 小时执行一次 |

### 4.4 保存配置

修改配置后，点击 **保存** 按钮使配置生效。配置保存后立即生效，下一次清理任务将按照新的配置执行。

---

## 5. 清理机制

### 5.1 清理逻辑

1. 系统按照配置的 Cron 表达式定时触发清理任务
2. 计算截止日期：当前时间 - 保留天数
3. 批量删除截止日期之前的审计日志
4. 每次删除的数量不超过配置的批量删除数量
5. 如果剩余记录仍然超过批量删除数量，下一次定时任务继续清理

### 5.2 注意事项

- 清理操作不可逆，删除后无法恢复
- 建议先设置较长的保留天数，确认无问题后再缩短
- 批量删除数量不宜过大，避免影响数据库性能
- 清理任务在后台执行，不影响正常使用

---

## 6. 最佳实践

1. **生产环境启用自动清理**：避免审计日志无限增长
2. **合理设置保留天数**：根据合规要求设置，通常 90 天足够
3. **选择低峰时段清理**：默认凌晨 3:00，可根据业务调整
4. **定期检查清理效果**：确认清理任务正常执行
5. **重要日志提前归档**：在清理前导出重要的审计日志

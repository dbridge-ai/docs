# 许可证管理

## 1. 功能概述

DBridge 采用设备指纹 + Ed25519 证书签名的许可证管理机制，支持在线和离线两种激活方式。系统提供 14 天试用期，到期后进入只读模式，需要激活许可证才能继续使用。

**核心能力**：
- 设备指纹识别
- 在线激活（一键认证）
- 离线激活（CSR 证书交换）
- 14 天免费试用
- 许可证状态监控

---

## 2. 许可证状态

### 2.1 查看许可证

在左侧导航栏中，点击 **许可证** 进入许可证管理页面。

### 2.2 状态信息

| 字段 | 说明 |
|------|------|
| 当前阶段 | 许可证状态 |
| 许可证 ID | 许可证唯一标识 |
| 试用剩余 | 试用期剩余天数 |
| 到期时间 | 许可证到期时间 |
| 证书路径 | 证书文件存储路径 |

### 2.3 阶段说明

| 阶段 | 颜色 | 说明 |
|------|------|------|
| Active | 绿色 | 许可证有效，所有功能正常 |
| Grace | 橙色 | 许可证即将过期，处于宽限期 |
| Readonly | 金色 | 许可证已过期，系统进入只读模式 |
| Locked | 红色 | 系统被锁定，无法使用 |

### 2.4 设备信息

页面显示当前设备的指纹信息（Machine Hash），用于许可证绑定。设备指纹是只读的，不可修改。

---

## 3. 试用

### 3.1 开始试用

首次使用 DBridge 时，系统处于 Locked 状态。点击 **开始试用（14 天）** 按钮，即可激活 14 天免费试用。

### 3.2 试用权益

试用期间，系统功能与正式许可证一致，无功能限制。

### 3.3 试用到期

试用到期后，系统进入 Locked 状态，需要激活正式许可证。

---

## 4. 在线激活

在线激活适用于 DBridge 服务器可以访问互联网的场景。

### 4.1 操作步骤

1. 进入 **许可证** 页面
2. 点击 **激活设备** 按钮，进入激活向导
3. 选择 **在线认证**
4. 点击 **在线认证** 按钮
5. 系统自动与许可服务器通信，完成激活
6. 激活成功后，自动跳转到主页

### 4.2 前提条件

- DBridge 服务器可以访问许可服务器
- 设备指纹未被其他许可证占用
- 有效的许可证配额

---

## 5. 离线激活

离线激活适用于 DBridge 服务器无法访问互联网的安全环境。

### 5.1 操作步骤

1. 进入 **许可证** 页面
2. 点击 **激活设备** 按钮，进入激活向导
3. 选择 **离线认证**
4. 点击 **生成请求** 按钮
5. 系统生成 CSR（证书签名请求），显示在文本框中
6. 点击 **复制请求** 按钮，将 CSR 复制到剪贴板
7. 将 CSR 发送给许可管理员（通过邮件、U 盘等方式）
8. 许可管理员使用 CSR 生成签名证书
9. 将签名证书返回到 DBridge 服务器
10. 在第二个文本框中粘贴签名证书
11. 点击 **提交响应** 按钮
12. 激活成功后，自动跳转到主页

### 5.2 CSR 格式

CSR 是一段包含设备指纹和公钥信息的文本，格式如下：

```
-----BEGIN CERTIFICATE REQUEST-----
[Base64 编码的请求数据]
-----END CERTIFICATE REQUEST-----
```

---

## 6. 证书状态

### 6.1 查看证书

在激活向导页面顶部，显示证书状态：

- **有效**（绿色）：证书有效，显示到期日期
- **无效**（黄色）：证书无效或不存在

### 6.2 刷新证书

当许可证处于 Grace 或 Readonly 状态时，可以点击 **刷新证书** 按钮，尝试从许可服务器更新证书。

---

## 7. 许可证生命周期

```
首次安装
    │
    ▼
  Locked ──── 开始试用 ────► 试用中（14天）
    │                            │
    │                            ▼
    │                     试用到期 ────► Locked
    │                            │
    ▼                            ▼
  激活设备 ◄──────────── 获取许可证
    │
    ▼
  Active ──── 到期 ────► Grace ────► Readonly ────► Locked
    │
    ▼
  刷新证书（续期）
```

## 8. 常见问题

### 8.1 更换服务器后许可证失效

许可证与设备指纹绑定。更换服务器后，设备指纹变化，需要重新激活。请联系许可管理员迁移许可证。

### 8.2 离线激活的签名证书如何获取

将 CSR 发送给 DBridge 许可管理员，管理员使用许可管理工具生成签名证书并返回。

### 8.3 试用期可以延长吗

试用期为 14 天，不可延长。如需继续使用，请激活正式许可证。

### 8.4 许可证到期后数据会丢失吗

不会。许可证到期后系统进入只读模式，已有数据完整保留。激活许可证后即可恢复正常使用。

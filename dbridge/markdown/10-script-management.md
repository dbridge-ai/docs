# 脚本管理

脚本管理功能提供 SQL 脚本文件的目录化管理，支持创建、编辑、组织 SQL 脚本，并自动保存编辑内容。

## 功能概述

- 目录树管理 SQL 脚本文件
- Monaco 编辑器编写 SQL
- 自动保存（1 秒防抖）
- 创建文件和文件夹
- 重命名、删除
- 面包屑导航

## 页面布局

```
┌──────────────┬─────────────────────────────┐
│  脚本目录树   │  面包屑: 首页 / 报表 / 月报  │
│              ├─────────────────────────────┤
│  📁 报表      │                             │
│    📄 月报.sql │  SELECT                    │
│    📄 日报.sql │    date,                   │
│  📁 迁移      │    COUNT(*)                │
│    📄 v1.sql   │  FROM orders               │
│    📄 v2.sql   │  GROUP BY date             │
│              │                             │
│              │          Monaco 编辑器        │
└──────────────┴─────────────────────────────┘
```

## 目录树操作

### 创建文件

1. 右键点击目标文件夹
2. 选择「新建文件」
3. 输入文件名（必须以 `.sql` 结尾）
4. 文件创建后自动打开编辑器

### 创建文件夹

1. 右键点击目标位置
2. 选择「新建文件夹」
3. 输入文件夹名称

### 重命名

1. 右键点击文件或文件夹
2. 选择「重命名」
3. 输入新名称

### 删除

1. 右键点击文件或文件夹
2. 选择「删除」
3. 确认后删除（文件夹会递归删除其中所有文件）

## 编辑器

脚本编辑器基于 Monaco Editor，与 SQL 编辑器使用相同的编辑引擎：

- SQL 语法高亮
- 自动补全
- 查找/替换
- 多光标
- 代码折叠

### 自动保存

编辑内容自动保存，无需手动操作：

- 每次按键后 1 秒内自动保存
- 保存状态在编辑器标题栏显示
- 关闭页面后再打开，内容完整保留

## 面包屑导航

编辑器上方显示当前文件的路径面包屑，如：

```
首页 / 报表 / 月报.sql
```

点击面包屑中的任意层级可快速跳转。

## 使用场景

### 常用 SQL 收藏

将常用的查询语句保存为脚本文件，按业务分类组织：

```
📁 常用查询
  📄 用户统计.sql
  📄 订单分析.sql
  📄 库存检查.sql
```

### 数据库迁移

将迁移 SQL 按版本组织：

```
📁 迁移脚本
  📄 v1.0_init.sql
  📄 v1.1_add_user_role.sql
  📄 v1.2_create_index.sql
```

### 报表模板

将报表查询保存为模板，定期执行：

```
📁 报表
  📄 日报.sql
  📄 周报.sql
  📄 月报.sql
```

# 数据库管理

数据库管理页面提供可视化的数据库对象管理功能，包括 Schema、表、视图、索引、约束的查看与管理。

## 功能概述

- 浏览数据库结构（Schema / 表 / 视图）
- 查看表详细结构（列、索引、约束、DDL）
- 在线修改表结构（新增/修改/删除列、索引）
- 创建表、创建视图
- 查看视图定义
- 数据库级操作（因数据库类型而异）

## 页面入口

有两种方式进入数据库管理：

1. **导航菜单** — 点击左侧菜单「数据库管理」
2. **数据源快捷操作** — 在数据源列表中点击「查询」旁的管理按钮

## 数据库列表

页面顶部展示当前连接下的所有数据库（MySQL）或 Schema（PostgreSQL / SQL Server）。

### 两级数据库

对于 MySQL、Oracle 等单级结构：
```
数据库 → 表/视图
```

对于 PostgreSQL、SQL Server 等两级结构：
```
数据库 → Schema → 表/视图
```

## 表列表

选择数据库/Schema 后，展示其中的表和视图：

| 列 | 说明 |
|:---|:-----|
| 名称 | 表/视图名称 |
| 类型 | TABLE / VIEW |
| 行数 | 预估行数 |
| 大小 | 数据占用空间 |
| 注释 | 表注释 |
| 引擎 | 存储引擎（MySQL） |
| 创建时间 | 表创建时间 |

## 表结构管理

点击表名进入表结构详情，包含以下标签页：

### 字段标签页

展示表的所有列信息：

| 列 | 说明 |
|:---|:-----|
| 列名 | 字段名称 |
| 类型 | 数据类型（varchar、int、datetime 等） |
| 长度 | 类型长度/精度 |
| 可空 | 是否允许 NULL |
| 默认值 | 默认值 |
| 键 | PRI（主键）/ UNI（唯一）/ MUL（索引） |
| 额外 | auto_increment 等 |
| 注释 | 列注释 |

**操作按钮**（admin/operator 可见）：

- **新增列** — 打开新增列对话框
- **编辑** — 修改列属性
- **删除** — 删除列（高危，需确认）

### 索引标签页

展示表的所有索引：

| 列 | 说明 |
|:---|:-----|
| 索引名 | 索引名称 |
| 类型 | PRIMARY / UNIQUE / INDEX / FULLTEXT |
| 包含列 | 索引包含的列 |
| 注释 | 索引注释 |

### 约束标签页

展示表的约束信息：

| 列 | 说明 |
|:---|:-----|
| 约束名 | 约束名称 |
| 类型 | FOREIGN KEY / UNIQUE / CHECK |
| 列 | 约束涉及的列 |
| 引用表 | 外键引用的表 |
| 引用列 | 外键引用的列 |
| ON DELETE | 删除时行为（CASCADE / RESTRICT / SET NULL） |
| ON UPDATE | 更新时行为 |

### 建表语句标签页

以 Monaco 编辑器只读展示完整的 CREATE TABLE DDL 语句。

- 支持语法高亮
- 右上角「复制」按钮，一键复制到剪贴板

### 表信息标签页

展示表的元信息：

| 信息 | 说明 |
|:-----|:-----|
| 存储引擎 | InnoDB / MyISAM 等 |
| 字符集 | utf8mb4 等 |
| 排序规则 | utf8mb4_unicode_ci 等 |
| 行格式 | Dynamic / Compact 等 |
| 预估行数 | 表的大致行数 |
| 创建时间 | 表创建时间 |
| 更新时间 | 最后修改时间 |
| 表注释 | 表的注释信息 |

## 修改表结构

### 新增列

1. 点击 **「+ 新增列」** 按钮
2. 填写列信息：

| 字段 | 说明 |
|:-----|:-----|
| 列名 | 新列的名称 |
| 类型 | 数据类型（从白名单选择） |
| 长度 | 类型长度/精度 |
| 可空 | 是否允许 NULL |
| 默认值 | 默认值 |
| 注释 | 列注释 |
| 位置 | 放在哪列之后（MySQL 有效） |

3. 点击「确定」
4. 系统生成 ALTER TABLE DDL 预览
5. 确认无误后点击「执行」

### 修改列

1. 在字段列表中找到目标列
2. 点击「编辑」按钮
3. 修改列属性
4. 系统生成 ALTER TABLE MODIFY COLUMN DDL
5. 预览并确认执行

### 删除列

1. 在字段列表中找到目标列
2. 点击「删除」按钮
3. 系统弹出警告（高危操作）
4. 确认后生成 ALTER TABLE DROP COLUMN DDL
5. 预览并确认执行

> 删除列会永久丢失该列数据，请谨慎操作。

### 变更预览与执行

所有表结构修改都遵循「预览 → 确认 → 执行」流程：

1. **预览** — 系统生成 DDL 语句和回退 DDL
2. **警告** — 高危操作（如 DROP COLUMN）会显示红色警告
3. **确认** — 用户可以在 Monaco 编辑器中微调 DDL
4. **执行** — 确认后执行，结果写入审计日志
5. **回退** — 系统自动保存回退脚本，以备恢复

## 创建表

1. 在 Schema 树中右键点击数据库/Schema
2. 选择「创建表」
3. 填写表名、注释
4. 添加列定义
5. 预览 DDL
6. 确认创建

## 创建视图

1. 在 Schema 树中右键点击数据库/Schema
2. 选择「创建视图」
3. 填写视图名称
4. 编写视图 SQL
5. 预览 DDL
6. 确认创建

## 查看视图定义

1. 在 Schema 树中右键点击视图
2. 选择「查看视图定义」
3. 系统以只读方式展示视图的 SELECT 语句

## 权限控制

| 角色 | 查看 | 修改 |
|:-----|:-----|:-----|
| admin | 可以 | 可以 |
| operator | 可以 | 可以 |
| developer | 可以 | 不可以 |
| viewer | 可以 | 不可以 |

无修改权限的用户，所有编辑按钮隐藏，Drawer 为只读模式。

# SQL 编辑器与数据查询

SQL 编辑器是 DBridge Pro 的核心功能页面，提供 SQL 编写、执行、数据浏览和编辑的一站式工作区。

## 页面布局

SQL 编辑器采用四区域布局：

```
┌──────────┬──────────────────────────┬──────────┐
│          │     SQL 编辑区            │          │
│  Schema  │   (Monaco Editor)        │   AI     │
│   树     │                          │  助手    │
│          ├──────────────────────────┤  面板    │
│          │     查询结果区            │          │
│          │   (数据表格)              │          │
└──────────┴──────────────────────────┴──────────┘
```

| 区域 | 说明 |
|:-----|:-----|
| 左侧面板 | Schema 树形导航，可拖拽调整宽度 |
| 中上区域 | Monaco SQL 编辑器，支持多标签页 |
| 中下区域 | 查询结果表格 |
| 右侧面板 | AI 助手对话面板，可折叠 |

## Schema 树

左侧面板展示当前数据源的数据库结构：

```
📁 数据库名
  📁 schema（PostgreSQL/SQL Server）
    📋 表名
      📄 列名（类型）
    📋 视图名
```

### 树节点操作

| 操作 | 方式 | 说明 |
|:-----|:-----|:-----|
| 展开/折叠 | 点击箭头 | 展开数据库、schema、表结构 |
| 生成 SELECT | 单击表名 | 自动生成 `SELECT * FROM table LIMIT 100` |
| 查看表结构 | 右键 → 查看表结构 | 打开表结构 Drawer |
| 复制 DDL | 右键 → 复制 DDL | 复制建表语句到剪贴板 |
| 创建表 | 右键 → 创建表 | 打开建表向导 |
| 创建视图 | 右键 → 创建视图 | 打开创建视图对话框 |
| 查看视图定义 | 右键 → 查看视图定义 | 只读查看视图 SQL |

## SQL 编辑器

### Monaco 编辑器

基于 VS Code 同款编辑器，支持：

- SQL 语法高亮
- 自动补全（表名、列名、关键字）
- 多光标编辑
- 查找/替换（Ctrl+F / Ctrl+H）
- 代码折叠
- 小地图

### 执行 SQL

| 操作 | 快捷键 | 说明 |
|:-----|:---------|:-----|
| 执行全部 | Ctrl+Enter | 执行编辑器中的全部 SQL |
| 执行选中 | Ctrl+Shift+Enter | 仅执行选中的 SQL 片段 |

### 多标签页

编辑器支持多标签页，最多 10 个：

- 每个标签页可以是 SQL 编辑、表数据浏览、或 Schema 列表
- 超过 10 个时，自动关闭最久未使用的标签页（LRU）
- 标签页之间独立，互不影响

## 查询结果

执行 SQL 后，结果在下方表格中展示：

### 结果表格功能

| 功能 | 说明 |
|:-----|:-----|
| 列排序 | 点击列头排序 |
| 列筛选 | 点击列头筛选按钮 |
| 分页 | 底部分页控件 |
| 横向滚动 | 列多时可横向滚动 |
| 行号 | 左侧显示行号 |
| 执行耗时 | 底部显示查询耗时 |
| 总行数 | 底部显示结果总行数 |

### 导出结果

查询结果可以导出：

1. 点击结果区域工具栏的 **「导出」** 按钮
2. 选择导出格式（CSV / JSON）
3. 下载文件

## 数据浏览与编辑

### 浏览表数据

1. 在 Schema 树中单击表名
2. 系统自动生成 `SELECT` 查询并执行
3. 结果在下方表格中展示

### 编辑表数据

在表数据视图中，可以直接编辑数据：

| 操作 | 方式 | 说明 |
|:-----|:-----|:-----|
| 编辑单元格 | 双击单元格 | 进入编辑模式，修改后按 Enter 保存 |
| 新增行 | 点击 **「+ 新增行」** | 在表格底部添加空行 |
| 删除行 | 选中行 → 点击删除 | 支持批量删除 |
| 行详情 | 点击行展开按钮 | 查看单行全部字段 |

> 数据编辑操作会写入审计日志。

## 表结构 Drawer

双击表名或右键选择「查看表结构」，打开表结构面板：

### 标签页

| 标签页 | 内容 |
|:-------|:-----|
| 字段 | 列名、类型、长度、可空、默认值、注释 |
| 索引 | 索引名、类型、包含列 |
| 约束 | 约束名、类型、引用关系 |
| 建表语句 | DDL 语句（Monaco 只读展示） |
| 表信息 | 引擎、字符集、排序规则、行数、创建时间 |

### 结构编辑（admin/operator）

有权限的用户可以在表结构 Drawer 中直接修改：

- **新增列** — 指定列名、类型、长度、可空、默认值、注释
- **编辑列** — 修改列属性
- **删除列** — 删除列（高危操作，需二次确认）
- **修改表注释** — 修改表的注释信息

修改操作会先生成 ALTER DDL 预览，确认后再执行。

## 脚本文件

SQL 编辑器集成了脚本文件管理：

1. 在编辑器中编写的 SQL 可以保存为脚本文件
2. 脚本文件按目录树组织
3. 支持自动保存（1 秒防抖）
4. 详见 [脚本管理](10-script-management.md) 章节

## AI 助手面板

右侧 AI 助手面板可以直接在当前查询上下文中对话：

1. 选择数据源和 Schema
2. 输入自然语言问题
3. AI 生成 SQL 并可直接执行
4. 详见 [AI 助手](12-ai-assistant.md) 章节

## 使用技巧

### 高效查询

- 在 Schema 树中双击表名，快速生成 SELECT 语句
- 选中部分 SQL 后按 Ctrl+Shift+Enter，只执行选中部分
- 使用 Ctrl+Space 触发自动补全

### 多数据源切换

在页面顶部可以切换数据源，切换后 Schema 树自动刷新。

### 大结果集处理

- 系统默认对 SELECT 查询添加 LIMIT 限制
- 如需查看全量数据，手动编写不带 LIMIT 的 SQL
- 注意：大结果集可能影响浏览器性能

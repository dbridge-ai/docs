# 报表面板

报表面板提供自定义 SQL 报表功能，支持将查询结果以表格、柱状图、折线图、饼图等多种图表形式展示。

## 功能概述

- 创建自定义 SQL 报表
- 多种图表类型支持
- 报表分类管理
- AI 辅助生成报表
- 报表预览
- 缓存配置

## 报表列表

进入「报表面板」页面：

- **左侧** — 报表分类树
- **右侧** — 报表卡片网格

### 分类管理

左侧分类树支持以下操作：

| 操作 | 说明 |
|:-----|:-----|
| 新建分类 | 创建新的报表分类 |
| 编辑名称 | 修改分类名称 |
| 移动 | 调整分类位置 |
| 添加子分类 | 创建嵌套分类 |
| 删除 | 删除分类（需确认） |

### 报表卡片

每个报表以卡片形式展示，包含：
- 报表名称
- 描述
- 图表预览缩略图

## 创建/编辑报表

### 基本信息

| 字段 | 说明 |
|:-----|:-----|
| 名称 | 报表名称 |
| 描述 | 报表说明 |
| 数据源 | 选择查询的数据源 |
| 数据库 | 选择数据库 |
| Schema | 选择 Schema（如适用） |
| 分类 | 报表所属分类 |
| 图表类型 | 展示形式 |
| 缓存时间 | 查询结果缓存时长（秒） |
| 图表配置 | JSON 格式的图表参数 |

### SQL 编辑

在 Monaco 编辑器中编写报表查询 SQL：

```sql
SELECT
    DATE(created_at) AS date,
    COUNT(*) AS order_count,
    SUM(amount) AS total_amount
FROM orders
WHERE created_at >= DATE_SUB(NOW(), INTERVAL 30 DAY)
GROUP BY DATE(created_at)
ORDER BY date
```

### 图表类型

| 类型 | 说明 | 适用场景 |
|:-----|:-----|:---------|
| table | 数据表格 | 通用数据展示 |
| bar | 柱状图 | 分类对比 |
| line | 折线图 | 趋势变化 |
| pie | 饼图 | 占比分布 |
| area | 面积图 | 累积趋势 |
| bar_grouped | 分组柱状图 | 多系列对比 |
| bar_stacked | 堆叠柱状图 | 组成分析 |
| bar_percent | 百分比柱状图 | 百分比组成 |
| area_percent | 百分比面积图 | 百分比趋势 |
| area_basic | 基础面积图 | 简单趋势 |
| line_series | 多系列折线图 | 多指标趋势 |

### 图表配置

图表配置为 JSON 格式，不同图表类型有不同的配置项。示例：

**折线图配置**：
```json
{
  "xField": "date",
  "yField": "total_amount",
  "seriesField": "category",
  "title": "月度销售趋势"
}
```

**饼图配置**：
```json
{
  "angleField": "count",
  "colorField": "status",
  "title": "订单状态分布"
}
```

页面提供「图表配置帮助」面板，展示每种图表类型的配置示例。

### 执行预览

点击「执行并预览」按钮：

1. 系统执行 SQL 查询
2. 根据图表配置渲染图表
3. 在预览区域展示结果

## AI 生成报表

系统支持通过 AI 自动生成报表：

1. 在报表编辑页面，找到 AI 生成面板
2. 输入报表描述，如："统计最近 30 天每日订单量和销售额"
3. AI 自动生成：
   - SQL 查询语句
   - 报表名称
   - 推荐图表类型
4. 预览确认后保存

> AI 生成需要配置 AI Provider。

## 报表预览

在报表列表中，点击报表卡片的「预览」按钮：

- 弹出预览窗口
- 渲染图表
- 展示数据

## 缓存配置

报表支持查询结果缓存，避免频繁执行复杂 SQL：

| 配置 | 说明 |
|:-----|:-----|
| 缓存时间 | 缓存有效期（秒），0 表示不缓存 |
| 缓存刷新 | 缓存过期后自动重新查询 |

## 使用场景

### 业务看板

创建关键业务指标的报表：

```
📁 业务看板
  📄 日活用户趋势（折线图）
  📄 收入分布（饼图）
  📄 各区域销售对比（柱状图）
```

### 运维监控

创建数据库运维相关报表：

```
📁 运维监控
  📄 慢查询统计（表格）
  📄 表空间使用（柱状图）
  📄 连接数趋势（折线图）
```

### 数据分析

创建数据分析报表：

```
📁 数据分析
  📄 用户增长趋势（面积图）
  📄 产品销量排行（分组柱状图）
  📄 渠道转化率（百分比柱状图）
```

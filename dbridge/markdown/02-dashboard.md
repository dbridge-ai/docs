# 仪表盘

仪表盘是登录后的首页，提供系统运行状况的概览和自定义数据视图。

## 功能概述

仪表盘包含两类内容：

- **系统概览** — 固定的统计卡片，展示数据源数量、同步任务数量、查询次数、成功率等核心指标
- **自定义仪表盘** — 用户创建的标签页，关联后端仪表盘视图，以图表方式展示自定义数据

## 系统概览

进入系统后，默认显示概览标签页，包含以下信息：

### 统计卡片

| 卡片 | 说明 |
|:-----|:-----|
| 数据源数量 | 当前系统中配置的数据源总数 |
| 同步任务数量 | 已创建的同步任务总数 |
| 查询次数 | 累计 SQL 查询执行次数 |
| 成功率 | 查询执行的成功百分比 |

### 系统信息

| 信息 | 说明 |
|:-----|:-----|
| 系统版本 | 当前 DBridge Pro 版本号 |
| 运行状态 | 服务是否正常运行 |
| 审计日志数 | 累计审计日志条数 |

## 自定义仪表盘

### 添加标签页

1. 点击标签栏右侧的 **"+"** 按钮
2. 系统创建一个新的仪表盘标签页
3. 新标签页关联后端的仪表盘视图（Dashboard View）

### 仪表盘视图

每个自定义标签页对应一个仪表盘视图，视图中包含多个图表组件。支持的图表类型：

| 图表类型 | 说明 |
|:---------|:-----|
| 柱状图 | 分类数据对比 |
| 折线图 | 趋势变化展示 |
| 饼图 | 占比分布 |
| 面积图 | 累积趋势 |
| 分组柱状图 | 多系列对比 |
| 堆叠柱状图 | 组成分析 |
| 百分比柱状图 | 百分比组成 |

### 删除标签页

点击标签页上的关闭按钮即可删除。系统概览标签页不可删除。

## 使用场景

- **日常监控** — 快速了解系统整体运行状况
- **数据展示** — 通过自定义仪表盘展示关键业务指标
- **团队共享** — 团队成员看到相同的系统状态

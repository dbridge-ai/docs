# 数据库巡检

## 1. 功能概述

数据库巡检功能通过采集数据库服务器的运行指标，结合 AI 分析，生成全面的数据库健康检查报告。系统自动进行多轮指标采集，捕捉数据库在不同时刻的运行状态，然后由 AI 综合分析并给出优化建议。

**核心能力**：
- 10 轮指标自动采集（每 10 秒一轮）
- 多维度指标覆盖（连接、吞吐、缓存、锁、复制、存储）
- AI 智能分析诊断
- 巡检报告历史管理
- 报告详情查看与复制

---

## 2. 进入巡检

巡检功能集成在 **服务器管理** 中。操作步骤：

1. 进入 **数据源管理** 页面
2. 找到目标数据源，点击操作栏的 **服务器管理** 按钮
3. 在弹出的服务器管理窗口中，切换到 **巡检** 标签页

---

## 3. 增强巡检

### 3.1 启动巡检

点击 **增强巡检** 按钮开始巡检流程。整个流程分为两个阶段：

**阶段一：指标采集**

系统自动进行 10 轮指标采集，每轮间隔 10 秒，总计约 100 秒。

采集过程中：
- 页面显示进度条，展示当前完成的轮次（如 `5/10 rounds`）
- 底部提示剩余时间
- 如果某轮采集失败，系统会自动重试（最多 3 次，指数退避）

**阶段二：AI 分析**

指标采集完成后，系统将指标数据和服务器信息发送给 AI 进行分析。AI 会：
- 分析指标趋势变化
- 识别异常指标
- 诊断潜在问题
- 给出优化建议

分析过程中会显示阶段性提示（"正在诊断"、"正在生成报告"），整个过程可能需要 1-3 分钟。

### 3.2 取消采集

如果需要在采集过程中取消，点击正在进行的按钮（此时变为红色），即可终止采集。

### 3.3 采集的指标

| 维度 | 指标项 |
|------|--------|
| 连接 | 当前连接数、最大连接数、活跃查询数、等待锁连接数 |
| 吞吐 | 事务提交/回滚数、每秒查询数 |
| 缓存 | 缓冲命中率、脏页数 |
| 锁 | 锁总数、被阻塞数、死锁数 |
| 复制 | 复制延迟、复制状态 |
| 存储 | 数据库大小、表空间使用率 |

> **说明**：不同数据库类型支持的指标项不同，系统会根据实际返回的数据自动调整。

---

## 4. 巡检报告列表

巡检完成后，报告会出现在下方的表格中。

### 4.1 列表字段

| 列名 | 说明 |
|------|------|
| 时间 | 巡检执行时间 |
| 状态 | 巡检结果状态：ok（绿色）、warning（橙色）、critical/error（红色） |
| 摘要 | 巡检结果的简要描述 |
| 耗时 | 巡检总耗时（含指标采集和 AI 分析） |
| 操作 | 查看详情、删除 |

### 4.2 查看详情

点击 **查看详情** 按钮，弹出详情对话框，包含：

- **状态**：巡检结果状态
- **时间**：巡检执行时间
- **耗时**：巡检总耗时
- **摘要**：巡检结果简要描述
- **详细内容**：AI 生成的完整巡检报告（Markdown 格式渲染）

### 4.3 复制报告

在详情对话框中，可以复制报告内容：

- **复制 Markdown**：复制原始 Markdown 格式文本
- **复制纯文本**：复制转换为纯文本后的内容（去除 Markdown 标记）

---

## 5. 删除报告

对于不需要的报告，可以点击 **删除** 按钮移除。删除前会弹出确认对话框。

## 7. 使用建议

1. **定期巡检**：建议每天对核心数据库执行一次巡检
2. **关注趋势**：多次巡检报告可以对比，观察指标变化趋势
3. **重视告警**：如果巡检状态为 warning 或 critical，应尽快排查
4. **结合慢 SQL**：巡检发现性能问题后，配合慢 SQL 监控深入分析
5. **保存报告**：重要巡检报告建议复制保存，作为运维档案

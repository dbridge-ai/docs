# MCP 工具

MCP（Model Context Protocol）工具是 AI Agent 可以调用的功能单元。DBridge Pro 内置了丰富的 MCP 工具，同时支持创建自定义工具。

## 功能概述

- 查看内置 MCP 工具
- 创建自定义 SQL 工具
- 编辑和删除自定义工具
- 启用/禁用工具
- 权限级别管理

## 工具列表

进入「MCP 工具」页面，展示所有可用工具：

| 列 | 说明 |
|:---|:-----|
| 名称 | 工具显示名称 |
| Tool ID | 工具唯一标识 |
| 类型 | builtin（内置）/ custom（自定义） |
| 分类 | 工具所属类别 |
| 权限 | read / write / admin |
| 状态 | 启用/禁用开关 |
| 描述 | 工具功能说明 |

### 筛选

- **搜索** — 按名称搜索
- **分类筛选** — 按工具类别过滤
- **类型筛选** — 内置 / 自定义

## 自定义工具

除了内置工具，还可以创建自定义 SQL 工具：

### 创建自定义工具

1. 点击「新建」按钮
2. 填写工具信息：

| 字段 | 说明 |
|:-----|:-----|
| 名称 | 工具显示名称 |
| Tool ID | 唯一标识（英文，如 `my_custom_query`） |
| 描述 | 工具功能说明（AI 根据此描述决定何时调用） |
| 分类 | 工具类别 |
| 权限级别 | read / write / admin |
| SQL 模板 | 工具执行的 SQL 语句 |

3. SQL 模板支持参数占位符：

```sql
SELECT * FROM {{table_name}}
WHERE created_at >= '{{start_date}}'
LIMIT {{limit}}
```

4. 保存后工具立即可用

### 编辑自定义工具

1. 找到目标工具
2. 点击「编辑」按钮
3. 修改配置
4. 保存

> 内置工具不可编辑。

### 删除自定义工具

1. 找到目标工具
2. 点击「删除」按钮
3. 确认后删除

> 内置工具不可删除。

## 启用/禁用

通过开关控制工具是否可用：

- **启用** — Agent 可以调用该工具
- **禁用** — Agent 无法调用该工具

> 禁用工具不会删除配置，随时可以重新启用。

## 权限级别

| 级别 | 说明 | 示例 |
|:-----|:-----|:-----|
| read | 只读操作 | 查询、查看结构 |
| write | 写操作 | 创建表、修改数据 |
| admin | 管理操作 | 删除表、修改配置 |

Agent 调用工具时，系统会检查 Agent 的数据源权限是否满足工具的权限要求。
